# 프리즘 도미노

같은 각도끼리 도미노를 이어 모든 조각을 사용하는 12라운드 퍼즐입니다. 조각 고르기 → 뒤집기 → 빛 잇기. 막혔을 때 되돌리기 3회 또는 다시 시작을 사용합니다.

## 실행

Node.js 22 이상에서 npm test, npm run build, npm start. 의존성 설치가 필요 없습니다. Vercel에서 이 저장소를 Import하면 vercel.json의 설정으로 단독 빌드합니다.

## 학습 확인

중1 삼각형의 내각·외각 관계. 9수03-05 중 삼각형 부분만 확인합니다. 승리·수집은 학습 도달과 별개이며, 독립 확인 과제·도움과 재시도 기록·설명·교사 검토·JSON 내보내기를 제공합니다. 기록은 현재 브라우저에만 보관됩니다.

## 제작 근거

참고 게임의 공식 출처와 선택 근거는 design.json, 교과서 개념의 출처는 sources.json, 교육과정 범위는 assessment.json에 있습니다. 교과서 PDF와 추출 원문은 포함하지 않습니다. 이미지 5개는 내장 image_gen으로 생성했으며 assets/prompts.json에 원문 프롬프트를 기록했습니다. 도형·문자·각도는 코드로 그립니다. 학생 대상 재미나 학습 효과 검증을 수행한 제품은 아닙니다.
